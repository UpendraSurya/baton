# Simulated routing benchmark — 9 arms, 5 scenarios

300 tickets x 5 seeds per scenario, paired across arms; right-desk quality 85%; every dispatch $0.001; max_hops 6, reject cap 2; swarm prior weight on other desks 0.2. Generated by `bench/swarm_sim.py` in 26s, $0.

`p vs X` is an exact McNemar test on per-ticket outcomes; `+a/-b` counts tickets only this arm / only X delivered.
